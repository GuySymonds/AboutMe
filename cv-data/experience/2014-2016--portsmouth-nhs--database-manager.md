# Portsmouth NHS Trust — IT Database Manager

**Period:** November 2014 – May 2016  
**Industry:** Healthcare / NHS / Public Sector  
**Location:** Portsmouth, UK

## Overview

Responsible for the provision of effective, efficient, and fully integrated ICT operational services, maximising availability and data integrity for end-users across the Trust. Owned database platform strategy, operations, resilience, and improvement in a mission-critical NHS environment where service continuity and recoverability directly mattered.

## Responsibilities

- Management and administration of Trust mission-critical databases and applications
- Designing new and modified database systems covering security, performance, availability, and recovery requirements
- Developing robust upgrade, maintenance, and backup / restore processes in line with best practice
- Ensuring systems operated at optimum performance and availability for IT users and dependent services
- Managing backup and recovery procedures to meet current RPO and RTO requirements
- Providing operational support, technical escalation, and platform improvement leadership

## Key Achievements

- Delivered a new SQL Server platform that saved the Trust approximately £1,000,000 compared with the previous solution.
- Designed and delivered a Cassandra data platform for a Trust-critical project.
- Designed a database and SQL Server monitoring / management suite to improve operational visibility and supportability.
- Strengthened backup and recovery procedures across all systems to meet current RPO and RTO targets.
- Improved resilience and operational confidence across a database estate supporting critical healthcare services.

## Technologies & Tools

- Microsoft SQL Server (multiple versions)
- Apache Cassandra
- Database monitoring and management tooling
- Backup and recovery tooling
- Windows Server
- ITIL-aligned operational processes
