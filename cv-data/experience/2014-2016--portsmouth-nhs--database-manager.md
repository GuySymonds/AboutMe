# Portsmouth NHS Trust — IT Database Manager

**Period:** November 2014 – May 2016  
**Industry:** Healthcare / NHS / Public Sector  
**Location:** Portsmouth, UK

## Overview

Responsible for the provision of effective, efficient, and fully integrated ICT operational services, maximising availability and data integrity for end-users across the Trust. Owned the database platform strategy, operations, and improvement for a mission-critical NHS environment.

## Responsibilities

- Management and administration of all Trust mission-critical databases and applications
- Designing new and modified database systems addressing security, performance, availability, and recovery requirements
- Developing robust database server upgrade, maintenance, and backup/restore processes in line with best practice guidelines
- Ensuring systems operate at optimum performance and availability for IT users
- Managing backup and recovery procedures to meet current RPO and RTO requirements
- Providing day-to-day operational support and escalation management

## Key Achievements

- Delivered a new SQL Server platform, saving the NHS approximately £1,000,000 compared to the previous solution.
- Designed and delivered a Cassandra data platform for a Trust-critical project.
- Designed a database and SQL Server management and monitoring suite to improve operational visibility.
- Improved backup and recovery procedures across all systems to meet current RPO and RTO targets.

## Technologies & Tools

- Microsoft SQL Server (multiple versions)
- Apache Cassandra
- Database monitoring and management tooling
- Backup and recovery tooling
- Windows Server
- ITIL-aligned operational processes
