# IT Certifications

## CompTIA A+ Hardware

**Exam:** 220-221  
**Status:** Certified  
**Issuer:** CompTIA

Foundation-level certification covering PC hardware, including installation, configuration, maintenance, and troubleshooting.

## CompTIA A+ Software

**Exam:** 220-222  
**Status:** Certified  
**Issuer:** CompTIA

Foundation-level certification covering operating systems, networking, and software support.

## CompTIA Network+

**Exam:** N10-002  
**Status:** Certified  
**Issuer:** CompTIA

Covers networking concepts, infrastructure, network operations, security, and troubleshooting.

## Microsoft Windows 2000 Professional (MCP)

**Exam:** 70-210  
**Status:** Certified  
**Issuer:** Microsoft

Microsoft Certified Professional exam covering installation, configuration, and administration of Windows 2000 Professional.

## Microsoft Windows 2000 Server (MCP)

**Exam:** 70-215  
**Status:** Certified  
**Issuer:** Microsoft

Microsoft Certified Professional exam covering installation, configuration, and administration of Windows 2000 Server.

## Microsoft Windows 2000 Network Infrastructure (MCP)

**Exam:** 70-218  
**Status:** Certified  
**Issuer:** Microsoft

Microsoft Certified Professional exam covering managing, maintaining, and troubleshooting a Windows 2000 network environment.
