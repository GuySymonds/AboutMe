# AI & Machine Learning

## Summary

Practical experience building, integrating, and governing AI and ML capabilities — from early-career ML document processing to recent LLM platform thinking. Focused on building AI capabilities that are observable, compliant, cost-controlled, and safe to operate in regulated environments.

- RAG (Retrieval-Augmented Generation) — retrieval pipelines, chunking strategies, metadata design
- Prompt orchestration and tool/function calling
- Guardrails and human-in-the-loop patterns
- LLM evaluation: quality and safety evaluation pipelines
- Observability and drift monitoring for LLM systems
- Rate limiting and cost governance
- Compliance and sensitive data handling in AI systems
- Access control and audit trails for AI data access

### Machine Learning

- ML algorithm design for data classification
- NLP system design (proof of concept level)
- Azure ML integrations
- Embeddings and vector search
- Custom model integration into production systems

### AI-Assisted Development

- GitHub Copilot for development productivity
- ChatGPT and LLMs for planning, prototyping, code review, and documentation

### Document Processing / OCR
